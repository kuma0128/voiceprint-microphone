# 声紋マイク（Discord用）

登録した本人の声を手掛かりに、マイクへ入る別人の声を抑えるWindowsアプリです。一人で話している間は48 kHzの音質を保ったノイズ除去だけを行い、二人の声が重なった区間だけ本人音声抽出へ滑らかに切り替えます。処理と声紋保存はPC内で行い、声紋を外部へ送信しません。

## 初回セットアップ

1. `Start-VoiceprintMic.cmd` をダブルクリックします。
2. 画面で次を確認します。
   - マイク入力: `マイク (HyperX QuadCast S)`
   - Discordへ渡す出力: `スピーカー (Realtek High Definition Audio)`
   - `● ノイズ除去`
   - `● 標準の本人音声抽出`
3. `声紋を再登録` を押し、画面の文章を20秒間、普段の通話と同じ声量で読み続けます。途中で読み終わったら先頭から繰り返します。友達の声やスピーカー音が入らない静かな状態で行ってください。
4. 録音後、数秒待ちます。`特徴点 6個以上` と `登録品質: 良好` または `使用可能` が表示されたら登録成功です。小さすぎる音、音割れ、発話不足、特徴が不安定な録音は保存前に自動で拒否され、以前の声紋が残ります。
5. `フィルター開始` を押します。

声紋は `%APPDATA%\mellonella\enrollment.json` に保存され、次回から自動読込されます。旧版の `enrollment-separator.json` が残っていても使用しません。

## Discordの設定

- 入力デバイス: `ステレオ ミキサー (Realtek HD Audio Stereo input)`
- 出力デバイス: `ヘッドホン (VL-S3BT)`
- 入力音量: まず `70%`
- Discord側の「音声の分離」「Krisp」などのノイズ抑制: オフ（このアプリとの二重処理を避けるため）

Windowsの通常の再生先はVL-S3BTのままにします。声紋マイクだけをRealtekへ出し、ステレオミキサー経由でDiscordへ渡す構成です。

## 同じ音量で別人が話した場合

単純な音量ゲートではなく、192次元の声紋照合と重複発話検出、48 kHz本人音声抽出を組み合わせています。本人だけの区間は低帯域の分離器を通さないため、旧版にあった毎秒の継ぎ目や8 kHz化による「ガビガビ」を避けます。

本人判定には発話開始から約1秒分の音声が必要です。判定は0.25秒ごとに更新されます。二人同時に話している間は、混ざった声の本人スコアで本人まで止めず、登録声紋で条件付けした本人抽出モデルの結果を通します。また、抽出後に元の混合音を混ぜ戻さないため、大声の別人が出力へ漏れにくくなっています。

判定に使う音声の長さは短くできません。0.75秒に縮めると本人のスコアが約0.13下がり（実測: 下位5%が0.643→0.518）、別人のスコアはほとんど変わらないため、本人が標準の厳しさ0.45で止まってしまいます。応答の速さは0.25秒ごとの更新が担当しています。

100%の除去を保証するものではありません。本人と別人が極端に近い声質、強い残響、マイクの飽和、非常に短い相づちでは漏れや音質劣化が起こることがあります。実際の本人・友達の声で試し、必要なら再登録してください。

## 本人なのに「抑制中」が続く場合

`詳細設定` はフィルター実行中でも操作できます。変更は即時反映され、`%APPDATA%\mellonella\gate-settings.txt` に自動保存されます。

このバージョンで本人スコアの計算方法が変わりました。以前の設定が標準値 `0.45` より低い場合は、安全のため `0.45` へ移行します。以前から `0.45` より厳しく設定していた値と、途切れ保護・閉じ方は維持されます。調整し直した値は新しい形式で保存されます。

- **厳しさ**: 標準 `0.45`。本人が抑制される場合は `0.03` ずつ下げ、友達が通る場合は `0.03` ずつ上げます。実行中は「現在の本人スコア」も表示されます。同梱テスト音声での参考値は本人が `0.67`〜`0.80`、別の人が `0.24`〜`0.37` です。声質やマイクで値は変わるため、実際の環境で確認してください。
- **途切れ保護**: 標準 `500 ms`。短いスコア低下で音声を切らない時間です。長くすると本人は滑らかになりますが、話者交代後に別人を止めるまで少し遅くなります。
- **閉じ方**: 標準 `120 ms`。抑制へ移る音量カーブです。短いほど素早く、長いほど滑らかに閉じます。

迷った場合は **途切れにくい**・**標準**・**他人を厳しく** のプリセットから選べます。まず標準で本人と友達に交互に話してもらい、必要な方向へ調整してください。

## 音声が「ガビガビ」する場合

このバージョンで、途切れの主な原因を修正しました。

- 出力側に約64ミリ秒の余裕（バッファ）を持たせ、声紋照合などの処理が一瞬重くなっても音が途切れないようにしました。入力マイクと出力機器のわずかなクロック差は、音声を最大±0.2%だけ連続的に補正して吸収します。
- 声紋照合（ECAPA）を音声処理とは別のスレッドへ移しました。以前は毎秒4回、音声処理を数十ミリ秒止めていました。
- 二人が話している区間の切り替え時に、処理中だった10〜30ミリ秒の音声を捨てていた不具合を直しました。会話中は切り替えが何度も起きるため、これが繰り返しの途切れになっていました。
- 切り替え条件も、検出1回ではなく3回連続に変えて、頻繁な行き来を防いでいます。
- 二人が話している間の音量ゲートに保持時間を入れました。以前は無声の子音などで一瞬ゲートが閉じ、音が刻まれていました。
- 通常音声まで歪ませていた全域の `tanh` 圧縮を外し、クリップ寸前のピークだけを滑らかに抑える方式へ変えました。

それでも途切れる場合は、コンソールに毎秒出る `[audio-io] stats:` 行の `underruns` を確認してください。`+0` が続いていれば処理は足りています。増え続ける場合はPCの負荷が足りていないので、他のアプリを閉じてください。

## 声紋の追加登録（朝・夜など）

声は時間帯や体調で変わります。`＋声紋を追加登録` を押すと、保存済みの声紋を残したまま今の声を追加で登録できます。朝の声・夜の声・通話用の小声など、よく使う声の調子ごとに追加しておくと本人判定が安定します。`声紋を再登録` はすべて捨てて作り直す場合に使います。

照合は登録済みの特徴点それぞれと比べて一番近い値を採用するため、追加登録で本人の照合値が下がることはありません（以前は全特徴点の平均と比べていたため、朝の声と夜の声を登録すると平均がどちらでもない声になり、両方の判定が悪くなっていました）。ただし参照点が増えるほど似た別人にも一致する可能性がわずかに増えるため、必要な声の条件だけ登録し、友達の声でも厳しさを確認してください。

## 終了

画面の `フィルター停止` を押してから閉じます。タスクトレイに残った場合は、声紋マイクのアイコンから終了してください。
