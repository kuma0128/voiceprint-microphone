# 声紋マイク（Discord用）

登録した本人の声を手掛かりに、マイクへ同時に入る別人の声を抑えるWindowsアプリです。1秒ごとに音を2話者へ分離し、登録声紋に近い側だけをDiscordへ渡します。処理と声紋保存はPC内で行い、声紋を外部へ送信しません。

## 初回セットアップ

1. `Start-VoiceprintMic.cmd` をダブルクリックします。
2. 画面で次を確認します。
   - マイク入力: `マイク (HyperX QuadCast S)`
   - Discordへ渡す出力: `スピーカー (Realtek High Definition Audio)`
   - `● ノイズ除去`
   - `● 強力2話者分離（声紋選択）`
3. `声紋を再登録` を押し、画面の文章を20秒間、普段の通話と同じ声量で読み続けます。途中で読み終わったら先頭から繰り返します。友達の声やスピーカー音が入らない静かな状態で行ってください。
4. 録音後、分離後の本人声紋を作るため数秒待ちます。`特徴点 6個以上` と表示されたら登録成功です。
5. `フィルター開始` を押します。

声紋は `%APPDATA%\mellonella\enrollment.json` と `%APPDATA%\mellonella\enrollment-separator.json` に保存され、次回から自動読込されます。古い5秒方式の声紋では強力分離を開始できないため、初回は必ず再登録してください。

## Discordの設定

- 入力デバイス: `ステレオ ミキサー (Realtek HD Audio Stereo input)`
- 出力デバイス: `ヘッドホン (VL-S3BT)`
- 入力音量: まず `70%`
- Discord側の「音声の分離」「Krisp」などのノイズ抑制: オフ（このアプリとの二重処理を避けるため）

Windowsの通常の再生先はVL-S3BTのままにします。声紋マイクだけをRealtekへ出し、ステレオミキサー経由でDiscordへ渡す構成です。

## 同じ音量で別人が話した場合

単純な音量ゲートではなく、2話者分離と192次元の声紋照合を使うため、本人と同程度の音量の別人も抑制対象になります。同音量の日本語2話者によるローカル試験では、本人成分を約21 dB優先し、登録していない話者だけの入力は無音化できました。

約1秒の処理遅延があります。また、100%の除去を保証するものではありません。本人と別人が極端に近い声質、強い残響、マイクの飽和、非常に短い相づちでは漏れや音質劣化が起こることがあります。実際の本人・友達の声で試し、必要なら再登録してください。

## 終了

画面の `フィルター停止` を押してから閉じます。タスクトレイに残った場合は、声紋マイクのアイコンから終了してください。
