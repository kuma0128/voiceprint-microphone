# 声紋マイク（Discord用）

登録した本人の声を手掛かりに、マイクへ入る別人の声を抑えるWindowsアプリです。一人で話している間は48 kHzの音質を保ったノイズ除去だけを行い、二人の声が重なった区間だけ本人音声抽出へ滑らかに切り替えます。処理と声紋保存はPC内で行い、声紋を外部へ送信しません。

## 初回セットアップ

1. `Start-VoiceprintMic.cmd` をダブルクリックします。
2. 画面で次を確認します。
   - マイク入力: `マイク (HyperX QuadCast S)`
   - Discordへ渡す出力: `スピーカー (Realtek High Definition Audio)`
   - `● ノイズ除去`
   - `● 標準の本人音声抽出`
3. `声紋を再登録` を押し、画面の文章を20秒間、普段の通話と同じ声量で読み続けます。途中で読み終わったら先頭から繰り返します。友達の声やスピーカー音が入らない静かな状態で行ってください。
4. 録音後、数秒待ちます。`特徴点 6個以上` と `登録品質: 良好` または `使用可能` が表示されたら登録成功です。小さすぎる音、音割れ、発話不足、特徴が不安定な録音は保存前に自動で拒否され、以前の声紋が残ります。
5. `フィルター開始` を押します。

声紋は `%APPDATA%\mellonella\enrollment.json` に保存され、次回から自動読込されます。旧版の `enrollment-separator.json` が残っていても使用しません。

## Discordの設定

- 入力デバイス: `ステレオ ミキサー (Realtek HD Audio Stereo input)`
- 出力デバイス: `ヘッドホン (VL-S3BT)`
- 入力音量: まず `70%`
- Discord側の「音声の分離」「Krisp」などのノイズ抑制: オフ（このアプリとの二重処理を避けるため）

Windowsの通常の再生先はVL-S3BTのままにします。声紋マイクだけをRealtekへ出し、ステレオミキサー経由でDiscordへ渡す構成です。

## 同じ音量で別人が話した場合

単純な音量ゲートではなく、192次元の声紋照合と重複発話検出、48 kHz本人音声抽出を組み合わせています。本人だけの区間は低帯域の分離器を通さないため、旧版にあった毎秒の継ぎ目や8 kHz化による「ガビガビ」を避けます。

本人判定には約1秒分の発話が必要です。また、100%の除去を保証するものではありません。本人と別人が極端に近い声質、強い残響、マイクの飽和、非常に短い相づちでは漏れや音質劣化が起こることがあります。実際の本人・友達の声で試し、必要なら再登録してください。

## 本人なのに「抑制中」が続く場合

`詳細設定` を開くと **本人判定のしきい値** スライダーがあります。標準は日本語・雑音環境向けの `0.30` です。本人の声が途切れる場合は `0.25` 前後まで下げ、他人の声が漏れる場合は少し上げてください。変更はフィルターを停止して再開すると反映されます。

## 声紋の追加登録（朝・夜など）

声は時間帯や体調で変わります。`＋声紋を追加登録` を押すと、保存済みの声紋を残したまま今の声を追加で登録できます。朝の声・夜の声・通話用の小声など、よく使う声の調子ごとに追加しておくと本人判定が安定します。`声紋を再登録` はすべて捨てて作り直す場合に使います。

## 終了

画面の `フィルター停止` を押してから閉じます。タスクトレイに残った場合は、声紋マイクのアイコンから終了してください。
